# Fuse Character Lab — Consistency Prompt Sets (GPT Image 2)

How to use these for **consistent** characters in ChatGPT (GPT Image 2):
1. **Image 1:** paste the BASE prompt → generate → pick the best result. That is now your **reference image**.
2. **Images 2–15:** start a message, **upload the reference image**, then paste the scene prompt (it already includes the IDENTITY block). The IDENTITY block is what keeps the same face.
3. Every ~4 images, re-upload your **newest best** result so the likeness never drifts.
4. Keep the IDENTITY wording **identical** every time — only the SCENE changes.
