② MUST-KNOW formulas (tables CANNOT do these for you)

Tables give probabilities & cut-offs — but you must still build the test statistic / set up the problem yourself. This is the irreducible list. Memorise ONLY these.

Standardising & descriptive

\( Z = \dfrac{X-\mu}{\sigma} \)
\( \bar{x}=\dfrac{\sum x}{n}, \quad s=\sqrt{\dfrac{\sum(x-\bar{x})^2}{n-1}} \)
\( CV = \dfrac{s}{\bar{x}}\times100\% \)

Binomial & Poisson (backup / means)

\( P(X{=}k)=\binom{n}{k}p^k q^{\,n-k} \)
Binomial: \( \mu=np,\ \sigma^2=npq \)
\( P(X{=}k)=\dfrac{e^{-\lambda}\lambda^{k}}{k!} \)
Poisson: \( \mu=\sigma^2=\lambda \quad (\lambda=np) \)

Test statistics

t: \( \dfrac{\bar{x}-\mu_0}{s/\sqrt{n}} \)   df = n−1
\( \chi^2=\sum\dfrac{(O-E)^2}{E} \),   E = (row×col)/total
F = \( \dfrac{\text{MS}_{B}}{\text{MS}_{W}} \),   df = (k−1, N−k)

Correlation & regression

\( r=\dfrac{n\sum xy-\sum x\sum y}{\sqrt{[n\sum x^2-(\sum x)^2][n\sum y^2-(\sum y)^2]}} \)
\( b=\dfrac{n\sum xy-\sum x\sum y}{n\sum x^2-(\sum x)^2},\quad a=\bar{y}-b\bar{x} \)
\( R^2=r^2 \)
That's the whole list. Everything else (looking up actual probabilities and critical values) is done by flipping to the right table.

③ How to READ each table + convert to what the question asks

A.3 Normal / Z-table — gives Φ(z) = P(Z ≤ z)

Question asksDo this
P(Z ≤ z)Read directly
P(Z > z)1 − Φ(z)
P(a < Z < b)Φ(b) − Φ(a)
Negative z, P(Z ≤ −z)1 − Φ(z) (symmetry)

Always convert X → Z first with Z = (X−μ)/σ. Then "number of people" = probability × total.

WantFrom P(X≤k)

A.2 Poisson — gives P(X ≥ x)

WantFrom P(X≥x)
P(X ≥ x)read directly

P(X ≤ k)1 − P(X≥k+1)
P(X < k)1 − P(X≥k)
P(X > k)P(X≥k+1)

A.4 χ², A.5 t, A.6 F — these give CRITICAL VALUES (not probabilities)

  • You compute your statistic with the formulas in ②, then compare to the table value.
  • Rule: if your calculated value > table (critical) value → Reject H₀ (significant).
  • t-table: pick column = tail probability (e.g. 0.05 or 0.025 for two-tailed), row = df.
  • χ²: row = df = (r−1)(c−1); column = α (usually 0.05).
  • F: column = df₁ (numerator, between), row = df₂ (denominator, within).

④ The 4 golden table tricks

Trick 1 — “≥ becomes 1 − ≤”. For discrete data: P(X ≥ 5) = 1 − P(X ≤ 4). Mixing up 4 and 5 is the classic slip — the boundary value belongs to whichever side has the "=".
Trick 2 — Binomial p > 0.5 symmetry. Your binomial table only goes to p = 0.5 (columns in sixteenths). For larger p, flip it: P(X = k | n, p) = P(X = n−k | n, 1−p). ⚠️ But it only has p = 1/16…8/16, so "clean" decimals like 0.2 / 0.8 aren't columns — for those, just use the binomial formula in ②.
Trick 3 — Normal symmetry. Φ(−z) = 1 − Φ(z). Half the curve = 0.5, so P(Z < 0) = 0.5 always. "Number of items" = probability × N.
Trick 4 — Poisson from Binomial. When n is large & p small (n>50, p<0.1), don't fight the binomial — set λ = np and use the Poisson table. (Exactly Assignment 3.)

⑤ Your assignments solved straight off the tables

Assignment 3 — Poisson, λ = np = 100×0.05 = 5  100% table-readable

  • (iii) P(X ≥ 5): go to Table A.2, column λ = 5, row x = 5 → read directly ≈ 0.5595. No summing!
  • (i) P(none) = P(X = 0): = 1 − P(X ≥ 1) → read row x = 1 at λ = 5, subtract from 1 → 0.0067.
  • (ii) P(X = 5): = P(X ≥ 5) − P(X ≥ 6) = (row 5) − (row 6) → 0.1755.

Assignment 2 — Normal, μ = 75, σ = 9  100% table-readable

  • Convert with Z = (X−75)/9, look up Φ(z) in A.3, then × 800.
  • (i) 67–72: Φ(−0.33) − Φ(−0.89) = 0.3707 − 0.1867 = 0.184 → ≈147 girls.
  • (ii) < 75: z = 0 → Φ(0) = 0.5 → 400 girls.
  • (iii) ≥ 70: 1 − Φ(−0.556) = 0.711 → ≈569 girls.

Assignment 6 — Binomial, n = 10, p = 0.8  use the FORMULA

p = 0.8 is not a column in this table (it only has sixteenths up to 0.5), so the table won't help here. Use P(X=7)=\binom{10}{7}(0.8)^7(0.2)^3 = 0.2013, mean = np = 8, var = npq = 1.6.

Bottom line: Bring the book, trust Tables A.1–A.6, and carry only the small ② list in your head. Write the direction reminder (≤ / ≥) on a sticky note if your lecturer allows it — otherwise just say it to yourself before every binomial/Poisson question.
