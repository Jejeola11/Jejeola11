One-time setup (do this once)
  1. Create a free Meta app at developers.facebook.com/apps → Create app → Business → add the Instagram product → API setup with Instagram login. Your IG must be a Business/Creator account.
  2. Generate a long-lived access token and copy your Instagram user ID (both on the Instagram product page). Add yourself as a tester — in dev mode it works on your own account, no app review. ✅
  3. In this Netlify site → Site settings → Environment variables, add the 4 below, then redeploy:
VERIFY_TOKENany word you choose (e.g. fuse123)
IG_USER_IDyour Instagram account id
IG_ACCESS_TOKENyour long-lived token
FUSE_AUTOMATIONSpaste the JSON the builder makes below
2
Connect the webhook (once)
  1. Meta app → Instagram → Webhooks → Add callback URL.
  2. Paste this Callback URL + your VERIFY_TOKEN, then Subscribe to the comments field. Save.
3
Build an automation for every post

Add one rule per video. Lock a rule to a specific post, or use a keyword that works across posts. Your work is saved on this device automatically.

Tap a post to attach an automation to it. (Needs your token + IG_USER_ID set + redeployed.)
Now paste that into the FUSE_AUTOMATIONS environment variable on this Netlify site and redeploy. That's it — every post fires its own DM. 🎉
